# TimeSlot — Working Version

This project uses the exact uploaded `TimeSlot.jsx` application as the main source.

## Run

Open a terminal in this folder and run:

```bash
npm install
npm run dev
```

Then open the localhost URL shown by Vite.

## Build

```bash
npm run build
npm run preview
```

Tailwind utility classes are loaded through the Tailwind CDN, while React, Lucide React and Recharts are installed through npm.
